# 🚀 Semiconductor Tech News AI Automation System

반도체 공정·소자·패키징 분야 취업 준비생을 위한 **AI 기반 글로벌 반도체 기술 뉴스 자동 수집 및 심층 분석 시스템**입니다. 매일 주요 외신(EE Times, SemiAnalysis, Tom's Hardware 등)의 최신 기술 기사를 자동으로 크롤링하고, 현직 엔지니어 관점의 하드코어한 공학적 심층 분석을 거쳐 노션(Notion) 데이터베이스에 체계적으로 아카이빙합니다.

---

## 📌 프로젝트 개발 및 개선 여정 (Evolution)

본 자동화 시스템은 단순한 기사 요약 봇에서 출발하여, 실무 면접과 포트폴리오에 즉시 활용할 수 있는 **초전문가 수준의 아카이빙 시스템**으로 거듭나기까지 다음과 같은 단계별 고도화 과정을 거쳤습니다.

### 1. 초기 모델 구축 및 RSS 요약의 한계 직면
* **구현 내용**: `feedparser`를 이용해 주요 반도체 RSS 피드의 글을 수집하고, OpenAI API를 통해 중요도를 분류한 뒤 노션 API로 업로드하는 기본 파이프라인을 구축했습니다.
* **마주한 문제**: RSS 피드에서 제공하는 짧은 요약글만으로는 기사의 핵심 기술이나 디테일을 담아내기 어려웠으며, AI 요약 역시 겉핥기식의 단순 개론 수준에 머물러 취업 준비생에게 실질적인 도움이 되지 않았습니다.

### 2. 본문 전체 크롤링(Scraping) 도입
* **개선 내용**: RSS 요약 의존을 탈피하고, 파이썬 `requests`와 `BeautifulSoup`을 활용해 기사 원문 URL에 직접 접속하여 본문 전체 텍스트를 누락 없이 긁어오도록 스크래핑 로직을 대폭 보강했습니다.
* **효과**: 외신 사이트의 불필요한 태그(광고, 네비게이션 등)를 정제하고 핵심 본문 영역을 타겟팅하여 AI가 풍부한 원문 데이터를 바탕으로 분석할 수 있는 기반을 마련했습니다.

### 3. 하드코어 공학 수준의 프롬프트 엔지니어링 (전문성 강화)
* **개선 내용**: AI의 페르소나를 "일반 요약가"에서 **"글로벌 반도체 선도 기업 15년 차 수석 엔지니어"**로 격상시켰습니다. 
  * 기존 레거시 공정/아키텍처 대비 물리적·구조적 차이점 분석
  * 공정 한계(RC 딜레이, 숏채널 효과, 열팽창계수 Mismatch 등) 및 수율(Yield) 향상 요인 서술
  * 실무 현장의 병목(Bottleneck) 및 트러블슈팅 포인트 도출
* **효과**: 교과서적인 설명에서 벗어나 학회(IEDM, ISSCC) 및 면접 수준의 날카롭고 깊이 있는 기술 분석 결과물이 생성되도록 개선했습니다.

### 4. 한글 제목 번역 및 '관련 기업' 자동 태깅 구현
* **개선 내용**: 
  * 영문으로 출력되던 기사 제목을 반도체 전문 용어가 살아있는 자연스러운 한국어 제목으로 자동 번역하여 노션에 기입되도록 수정했습니다.
  * AI가 기사 내에서 언급된 주요 반도체 기업(Samsung, SK Hynix, TSMC, Intel, NVIDIA 등)을 파싱하여 노션 데이터베이스의 '관련 기업' 속성에 자동으로 매칭되도록 연동 로직을 완성했습니다.
* **효과**: 노션 데이터베이스의 가독성이 극대화되었으며, 기업별·기술별 필터링과 아카이빙 관리가 매우 용이해졌습니다.

## 🛠️ 주요 기능

1. **자동 수집 (24시간 주기)**: 매일 지정된 글로벌 IT/반도체 매체의 최신 아티클 탐색 및 중복 URL 필터링
2. **원문 정밀 스크래핑**: 본문 전체 텍스트를 추출하여 데이터 손실 방지
3. **AI 하드코어 심층 분석**: 
   * **한글 제목 번역**: 직관적이고 전문적인 타이틀 생성
   * **기술 심층 분석**: 공정 원리, 기존 기술과의 대조군 비교, 수율 관점 서술
   * **직무 시사점**: 공정/소자/설비/패키징 엔지니어 관점의 실무 연결고리 및 면접 포인트
   * **핵심 전문 키워드**: 반도체 세부 기술 용어 추출
4. **노션(Notion) 자동 연동**: 중요도 분류, 출처, URL, 관련 기업 태그 및 심층 분석 본문을 노션 페이지로 자동 생성

## ⚙️ Tech Stack

* **Language**: Python 3.10+
* **Core Libraries**: `feedparser`, `BeautifulSoup4`, `requests`, `openai`, `notion-client`
* **Automation**: GitHub Actions (CI/CD 기반 스케줄러 자동 실행)
* **Target Platform**: Notion Database API
